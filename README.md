# RevenaPath

AI-powered chargeback recovery platform for consumer brands. Reclaim revenue lost to avoidable chargebacks with intelligent automation and AI-powered dispute resolution.

## Tech Stack

- **React 19** — UI framework
- **Vite 7** — Build tool
- **Tailwind CSS 4** — Styling
- **Framer Motion** — Animations
- **React Three Fiber / Three.js** — 3D visuals
- **Lucide React / React Icons** — Icons

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Scripts

| Command          | Description              |
| ---------------- | ------------------------ |
| `npm run dev`    | Start dev server         |
| `npm run build`  | Production build         |
| `npm run preview`| Preview production build |
| `npm run lint`   | Run ESLint               |
